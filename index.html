⚙️ Konfigurasi Repositori GitHub

Masukkan token akses GitHub Anda untuk mengizinkan halaman ini mengunggah file audio dan memperbarui songs.json secara otomatis ke repositori.

Token disimpan aman di localStorage browser laptop Anda sendiri dan tidak pernah dikirim ke pihak ketiga.

📖 Cara Membuat GitHub Token (Gratis & Mudah)

  1. Buka GitHub Personal Access Tokens (Login ke akun GitHub Anda).
  2. Klik Generate new token → pilih Generate new token (classic).
  3. Pada kolom Note, ketik nama bebas, misalnya: Upacara Song Uploader.
  4. Pada kolom Expiration, pilih masa berlaku (misal: No expiration atau 90 days).
  5. Centang kotak izin:
    • ✅ repo (Full control of private/public repositories).
  6. Scroll ke bawah dan klik tombol hijau Generate token.
  7. Salin kode token yang diawali dengan ghp_... lalu tempelkan ke form Pengaturan GitHub di portal ini. Selesai!
